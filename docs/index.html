Turn a headline into a live prediction market.

Panta Pulse is an agent-native creation engine for Panta. Give it a news item: it drafts the market, validates it against Panta's real on-chain constraints, gets the real fee quoted, and builds the real unsigned Solana transaction for a wallet to sign.

Creation, not another destination

The brief asked what prediction markets become when they are built into other products. So this is the engine other products call — not a place to browse markets.

headline ──▶ LLM drafts market
        ──▶ validated against Panta's constraints
        ──▶ POST /markets/create/quote/  → real USDC fee
        ──▶ POST /markets/create/build/  → real unsigned mainnet tx
        ──▶ wallet signs — we stop here, by design
        ──▶ POST /markets/create/register/  → market live and titled

The engine never signs and never broadcasts. That is Panta's custody model, in their words: "Panta cooks the transaction. The user signs. You file it on-chain."

The embeddable surface

This is the part that lives inside someone else's product. A normalised market becomes a generic card, or a Discord webhook payload, in one call. 

renderDiscordMessage(toEmbedCard(status, { appBaseUrl, createdFrom }))

Two API behaviours that cost real debugging time

BehaviourWhat happens
Trailing slash on the path /markets/?limit=2 is correct. /markets?limit=2 is a different, wrong route.
Image host validation imageUrl is soft-checked at quote and hard-checked at build. One popular placeholder host passes quote and then dies at build with an opaque unexpected create build failure.
Mixed timestamp shapes Unix seconds on mainnet, ISO strings in sandbox. The normaliser accepts both.
